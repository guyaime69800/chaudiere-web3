# Mascottes Simba

Images issues des deux pièces jointes fournies par Guy le 7 octobre 2026.
Les noms des assistants restent Shiba Bot et Shiba Devis.

- `simba-assistance-technique.webp` : Simba avec la clé à molette.
- `simba-accompagnement-administratif.webp` : Simba avec le stylo et le carnet.

Détourage réalisé avec l’outil imagegen intégré, fond transparent demandé.
Consignes : retirer uniquement le fond ; conserver le personnage entier,
les couleurs, les vêtements, les lunettes, les chaussures, la queue et
les accessoires de chaque image ; ne pas ajouter de texte ni recadrer.

Versions web : 768 × 1152 pixels, WebP qualité 90, transparence conservée.
L’affichage utilise `object-fit: contain` et des dimensions proportionnelles.
Le logo CarnetPass et les traitements des assistants ne sont pas modifiés.
